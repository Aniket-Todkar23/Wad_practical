PICT Syllabus

B.E. Computer Engineering

Select an academic year to view its core subjects:

First Year (FE)

  • Engineering Mathematics I & II
    Foundations of calculus, differential equations, and linear algebra.
  • Basic Electrical Engineering
    Introduction to basic electrical circuits and electromagnetism.
  • Programming and Problem Solving
    Fundamentals of programming using C, loops, arrays, and algorithms.

Second Year (SE)

  • Data Structures & Algorithms
    Study of trees, graphs, hashing, and algorithm complexity.
  • Object Oriented Programming
    Core concepts like inheritance and polymorphism using C++/Java.
  • Microprocessors
    Architecture and assembly level programming for processors (e.g., 8086).

Third Year (TE)

  • Database Management Systems
    Relational models, SQL, normalization, and NoSQL databases.
  • Computer Networks
    OSI model, TCP/IP Suite, routing, and switching fundamentals.
  • Theory of Computation
    Automata, formal languages, Turing machines, and decodability.

Final Year (BE)

  • Machine Learning
    Supervised/unsupervised learning, neural networks, and AI fundamentals.
  • Information & Cyber Security
    Cryptography, network security protocols, and ethical hacking basics.
  • Capstone Project
    Practical application of engineering concepts to solve a real-world problem.
